# Python ステップアップ問題集 答案用ノートブック

電子書籍『Python ステップアップ問題集』の付属データです。  
問題ごとに解答欄と検証セルが並んだ Google Colab 用のノートブックを、巻ごとに公開しています。

解答を書いて実行するだけで、正誤を確かめられます。

**案内ページ：** https://esfine.github.io/python-workbook/

## ノートブックに問題文は入っていません

入っているのは次の 3 つだけです。

- 問題番号の見出し
- 空の解答セル
- 検証セル

問題文・ヒント・解答例・解説は書籍に収録しています。  
書籍と一緒にお使いください。

書籍には検証コードもすべて載せているため、ノートブックを使わなくても最後まで進められます。

## 使い方

1. 下の表から、お持ちの冊の案内ページを開きます
2. 「Google Colab で開く」をクリックします
3. Colab の画面上部にある「ドライブにコピー」をクリックして、自分の複製を作ります
4. 書籍の問題を読み、解答セルにコードを書きます
5. 解答セルを実行してから、すぐ下の検証セルを実行します
6. `OK` と表示されれば正解です

公開しているノートブックは読み取り専用です。  
何を書いても元のノートブックには影響しません。
